# 公司情报 360 增量

## 已实现

- /company 复用既有 company/job/industry/unit/report/claim 数据，新增 jobs 与 diagnosis，不建立第二套公司记录。
- 岗位状态使用与岗位列表一致的证据判断（可能开放·待核验／已核验开放等），不再显示裸 OPEN。
- 关联岗位可跳转 Job360，而不是只列标题。
- 档案缺招聘入口但岗位带官方来源时：列出官方来源 origin，只有一个候选时给“采用为招聘入口”按钮；多来源冲突不自选，要求人工确认。
- 采用动作走既有 POST /company（按 id 更新 careers_url），不自动触发抓取，不改简历/岗位/投递。

## 语义修正

UNVERIFIED（有线索未证实）在评估中由“状态未知”改为“可能开放·待核验”；OPEN 历史仍为待核验，只有 7 天内带证据摘录的官方状态记录才是“已核验开放”。

## 验证

新增 3 项公司视图测试：单来源候选不写库、多来源不臆断、空岗位诚实空态。全量 433 项离线通过，构建与语法检查通过。

## 未验证

当前 GUI 的实际点击、公司详情滚动与窄屏表现尚未验收；真实“采用招聘入口”后的监控效果未在真实站点验证，且采用本身不会立即抓取岗位。
