# CareerOS v2.0 增量交付报告（终版，含未完成项）

更新：2026-11-18。基线：既有 CareerOS（schema14）增量升级，未清空数据、未改个人画像事实、未真实对外投递。

## 一、本轮新增（按提交顺序）

1. 研究结果持久化：脱敏快照存 sync_run.meta，重启可查、5 分钟内同条件复用、不代替入库授权。
2. 研究并发与卸载安全：默认单任务、超限明确 busy、卸载后拒绝新任务且迟到结果不写库。
3. 画像与简历中心分工：画像只维护事实偏好；导入/版本对比/解析确认集中在简历中心兼容入口，人工确认才写画像。
4. 公司情报 360：状态按证据显示、关联岗位可跳 Job360、缺招聘入口时给可确认的「采用」动作（多来源不臆断）。
5. 行业研究入口：空状态可建行业；检索计划 + 最多 3 次公开检索，保存来源与日期，固定「待核实」清单。
6. 投递日历视图：按上海本地日展示截止/跟进/已投递，逾期单列，未填日期单独列出。
7. 岗位横向对比：勾选最多 5 个，逐字段对比，无混合总分，未知写未知。
8. 面经观点聚合：按类别 × 年份 × 部门分组，小样本只作线索，相反立场标冲突。

## 二、此前已完成（同一轮 v2 增量）

后台浏览（研究 target background、启动最小化、显式登录激活）、研究预算/取消/去重、全库 SQL 筛选与分页、招聘状态证据门禁（OPEN/CLOSED/UPCOMING 需来源+摘录）、Eligibility/Fit/Evidence 三分、Job360 申请草稿与材料冻结、今日工作台与待办持久化、列表证据批量读取。
