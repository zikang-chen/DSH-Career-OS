# 研究结果持久化增量

- 复用sync_run.meta保存脱敏结果快照，无schema迁移；原始会话票据/cookie/securityId/token等不入持久结果。
- 单结果上限1.5MB，超限只保留审计和明确提示，不伪称全文已缓存。
- /research/task重启后优先读持久结果；/research/tasks提供最近记录。
- 五分钟内同条件成功只读预览可复用，force=true显式重取；预览缓存不能吞掉dryRun:false入库授权。
- 情报采集区增加“最近研究结果”，可查看保存文字和运行状态；不自动重新搜索。
- 中断running仍沿原reconcileRuns标error，不自动恢复网络任务；取消与失败保留脱敏结果（若有）。

验证：专项覆盖新manager读取持久结果、跨manager缓存不重新访问、独立入库授权、票据脱敏、体积限制；全量回归通过。当前GUI实际点击历史结果未验证。

限制：保存的图片访问票据已去除，不保证保存预览链接可直接打开原图。需要原图时使用知识库合法来源/本地已下载证据，不能拼造票据。跨重启续跑不是自动执行能力，仍需用户明确重试。
