# 知识库删除能力

## 已实现

- **单条删除**：情报中心卡片与资料详情都能删；两次点击确认（先点“删除”，再点“再次点击确认删除”），避免误删。
- **批量删除**：`POST /knowledge/delete` 支持 `ids`，逐条处理并分别返回 `removed` 与 `missing`，不会把不存在的 id 当成成功。
- **审计留痕**：删除前写入一条 `sync_run`（kind=`knowledge_delete`），记录 id/标题/类型/平台/关联来源/原因与时间。删除不可撤销，但“删过什么”可查。
- **只删条目本身**：连同该条目的历史修订（`knowledge_revision`）一起删；**不删除**关联岗位、面经原文记录、已下载图片文件。
- Agent 工具 `career_knowledge` 新增 `action=delete`，必须显式 `confirm=true` 才执行，并在描述里要求先向用户确认；无 confirm 直接返回错误，不删任何东西。

## 验证

新增 3 项离线测试：删除条目连带修订但保留来源岗位并留审计、批量删除分别报告成功与不存在、未知 id 拒绝且计数不变。全量 451 项通过。

## 边界

- 删除是硬删除，不提供“回收站”；需要保留时请用“归档资料”。
- 图片文件与知识库条目是分开的：删除条目不会清理 `data/` 下已下载的图片文件。
- 当前 GUI 的实际点击与窄屏表现未验收。
