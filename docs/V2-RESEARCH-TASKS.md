# v2 可取消的研究任务

界面采集使用/research/start立即返回任务ID，随后有限轮询/research/task；显示当前步骤与访问预算，提供取消。105秒界面等待后请求取消，不无限加载。后台预算90秒/6访问，内层截止控制与单任务取消使用共享signal。

同一范围与模式在途请求复用一个任务。日志保存到现有sync_run，插件启动reconcileRuns将遗留running标中断；不自动无限重跑。结果当前只保存在进程内最多30个，重启后日志保留但结果需重新按用户请求预览。

取消只停止新动作并清理本任务资源，已完成入库不会自动回滚删除。关闭插件会中止本进程管理的研究任务，不关闭共享浏览器。

已覆盖离线在途去重/终态审计/幂等取消测试。尚未验证当前GUI实际点击取消；当前页面卸载不会主动取消用户已发起任务，任务仍受服务端预算。不是完整跨重启任务恢复系统。
