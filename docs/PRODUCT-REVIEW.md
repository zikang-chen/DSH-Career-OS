# CareerOS 产品走查与交付边界

更新：2026-11-17。审查方式：独立UX子智能体只读审查 + 真实工具/API/站点验证 + 本地构建与回归。当前会话没有可控制的已认证DSH GUI，因此没有声称截图、亮暗主题或实际点击体验已完成验收。

## 已修复的主要任务断点

1. 岗位详情→准备简历/面试：统一传岗位ID；简历工作室默认进入定向出稿；面试页读取公司/岗位/JD，不重复手填。
2. 知识库→关联岗位：岗位资料可以回到岗位详情或准备简历；切换页签后保留知识库筛选及分页。
3. 手动导入→知识库：工具和HTTP两条入口同步幂等索引，重复资料不需要重启才能显示；历史资料可点“补建历史索引”。
4. 数据源：6组卡片不重复，组内BOSS/51job/小红书/牛客/OfferShow分别有登录入口；启用不等于已登录。
5. OCR：失败保留原因并刷新；原图按需加载；识别与用户核对分开；正文和OCR不相互覆盖。
6. 投递材料：收藏为草稿，首次正式投递冻结最终内容；后续源材料删除不会悄悄改变历史。

## 可用界面流程

- 设置→数据源→选择平台登录/续期。
- 知识库→采集资料→关键词/招聘类型→预览→明确确认入库。
- 知识库→类型/公司/平台/状态筛选→原文与来源→整理/归档→媒体OCR/核对。
- 岗位雷达→岗位详情→按岗位准备简历/面试→投递管理→状态和冻结材料复盘。

- 牛客已取回公开可见正文节选，存在后半段截断，不宣称完整全文；需要登录/权限时人工处理。
- 51job真实搜索/详情已成功，但某些渲染回合超时，显示失败而不返回无关推荐列表。
- OfferShow公司搜索需真实搜索框，校招计划与公开薪资热榜不同；完整薪资库未承诺。
