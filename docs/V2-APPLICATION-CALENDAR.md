# 投递日历视图增量

## 已实现

- 投递管理新增第三种视图“日历”，与清单、看板共用同一份投递记录（不复制数据）。
- 按上海本地日把三类已记录日期摊开：投递截止、你的下一步跟进、已投递日期；默认看未来 30 天。
- 逾期跟进单列一块，明确“仅表示你设置的跟进日已过，不代表招聘方回复”。
- 没有日期的记录单独折叠列出，不推断、不编日期；未来 30 天无日期时给空状态而非假日程。
- 每个条目可打开原投递详情（冻结材料、时间线）。

## 验证

新增 4 项离线测试：三类日期分组与逾期分离、无日期诚实列举、超期限日期不显示但数据不变、跨 UTC/上海的“今天”一致。全量 441 项通过，构建与语法检查通过。

## 未验证与边界

- 日历是列表视图而非月历网格，未做拖拽改期；修改日期仍需在投递详情/更新里进行。
- 截止日期来自岗位记录，仍需回官方页面核实。
- 当前 GUI 实际点击、窄屏与深色主题未验收。
