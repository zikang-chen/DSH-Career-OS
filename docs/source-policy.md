# 数据源政策与合规边界

> 具体到「哪个接口能用、怎么手动取回」的操作手册见 [source-playbook.md](source-playbook.md)。
> 本节只讲原则与边界。

原则顺序（越高越优先）：**官方 API > 授权接口 > robots 允许的公开页面 > 合规搜索摘要 > 用户手动导入**。

## 已接入

### 1. `official_careers` — 企业官方招聘页

- 方式：`fetch` 公开 GET，串行，默认间隔 2.5s，20s 超时。
- **先读 `robots.txt`**：`host/sources.js:robotsAllows()` 按 `User-agent: *` 分组解析 `Allow`/`Disallow`，最长匹配优先、同长度 `Allow` 优先；被禁止时**不抓取**，规则状态记为 `error` 并在提醒里说明原因。
- 提取：`parseCareersPage()` 拿候选岗位链接 + 页面级信号（`正在招聘` / `暂无职位` / `即将开启`），内容哈希用于变化检测。
- 局限：只读公开渲染出的 HTML；JS 动态渲染的招聘页可能拿不到岗位列表——此时页面级信号仍有效（能回答"招不招"）。

### 2. `web_search` — 合规搜索发现

- 走 DSH 自己的 `ctx.web.search()`（复用 Harness 已配置的搜索提供方），只取**标题 + 链接 + 摘要**。
- 结果一律标为线索，`UNVERIFIED`，不据此认定在招。

### 3. `manual` — 手动粘贴 / 用户导入

- 无网络请求，**永远不会被封**，是不可接入平台的统一兜底。
- `parsePastedJob()` 解析公司、岗位、地点、出勤天数、年级限制、截止日期、技能、链接；解析不到的字段留 `NULL`。

## 明确不接入（在「数据源健康」里可见）

| 来源 | 原因 |
| --- | --- |
| 实习僧 / BOSS 直聘 / 牛客招聘 / 智联 / 前程无忧 / 猎聘 / LinkedIn | 无官方开放接口；自动抓取违反平台条款与反爬规则 |
| 小红书 / 脉脉 / 知乎 / 百度贴吧 / 一亩三分地 | 需登录、禁止自动化采集 |

对这些来源，系统提供 **`career_social_queries`**：生成搜索关键词与各平台搜索链接，供你自己打开浏览，再把有用内容用 `career_forum_import` 粘贴进来。系统**不会**伪造没取到的正文。

`CONNECTOR_META` 里这些条目是 `accessMode: 'blocked'`、`enabled: false`，并在 `source_health` 表落库——限制是**看得见的**，不是隐藏的。

## 论坛信息的处理

- `accessMode` 记录获取方式：`manual_import` / `user_export` / `public_page` / `search_snippet`。
- 按 `(platform, content_hash)` 去重：**同一内容被转载不会变成多个独立证据**。
- 证据等级：
  - `A` 官方一手
  - `B` 多个独立来源互证
  - `C` 单一可溯源自述（默认）
  - `D` 未证实 / 互相冲突
  - `U` 信息不足
- 只保存短摘录与结构化观点，不存储整帖原文用于再分发。
- 不对论坛用户建画像，只保留公开昵称。

## 安全与隐私

- 简历原文、联系方式、投递记录**只在本机**；日志不写简历全文。
- 面板 API 做同源校验（`sec-fetch-site` / `Origin`），请求体上限 2MB。
- 删除数据需两步：`prepare` 拿 token → `commit` 回传，10 分钟过期。
- 不自动投递简历、不自动邮件、不修改外部账户——只有记录与提醒。
- 网页/论坛文本一律当**不可信数据**处理：解析只做结构化抽取，不据此执行指令。

## 时效策略

| 数据 | 刷新策略 |
| --- | --- |
| 在招状态 / 截止日期 | 高时效；`OPEN` 超过 21 天未核验 → `STALE` |
| 面试流程 | 中时效；按年份标注 |
| 实习体验 | 必须带年份与团队上下文 |
| 行业结构 | 低频（季度级） |

界面与工具输出都显示**上次核验时间**，不用"最近同步时间"冒充事实核验。
