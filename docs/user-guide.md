# 使用指南

## 打开面板

左侧边栏底部、设置按钮上方的 **🎯 求职面板**。面板内有 9 个页签：
总览 / 简历与画像 / 岗位雷达 / 投递管理 / 公司情报 / 行业研究 / 论坛与 Bar / 面试准备 / 设置。

对话里让 Agent 调用 `career_panel` 可以把它直接切到对应页签并聚焦某个岗位。

## 0. 先建立画像（3 分钟）

面板 →「简历与画像」：

1. **导入简历**：填本机文件绝对路径（`.md/.txt/.docx/.pdf`）或直接粘贴全文。
2. 系统给出**解析候选**（学校/学历/毕业年份/实习/项目/技能），标「需要你确认」。
3. 点「把解析结果写入画像」——**确认后才入库**。解析错的地方直接在下面的表单改。
4. 补上：可实习开始时间、每周出勤天数、目标城市、目标行业/岗位、排除条件。

> 留空 = 未知。系统不会替你猜学历、经历或量化指标。

## 1. 收岗位

三种方式，可混用：

- **粘贴 JD**：面板「岗位雷达」→ 新增岗位，把 JD 原文贴进去，公司+岗位名填上即可。系统自动解析地点、出勤、截止日、技能。
- **让 Agent 找**：`把这条 JD 存进 CareerOS`、`帮我找北京 AI 产品实习`。
- **官方招聘页监控**：面板「公司情报」登记公司 + `官方招聘页 URL`，然后在「设置」建一条 `careers_page` 规则或让 Agent 跑 `career_jobs_sync`。

同一岗位从不同来源重复保存会**合并来源**而不是新建（实测：`字节跳动` 与 `北京字节跳动科技有限公司` 会归一成同一家）。

## 2. 看匹配

`career_match_rank` / 面板岗位列表的分数。

分数 = 与**你的偏好**的匹配度，硬条件先过滤，再看六个维度：

| 维度 | 初始权重 |
| --- | --- |
| 核心资格与技能 | 30 |
| 项目与实践经历 | 20 |
| 职业兴趣 | 20 |
| 地点与时间 | 15 |
| 成长价值 | 10 |
| 信息新鲜度 | 5 |

权重可在 `career_profile_update` 的 `preferences.weights` 里改。

分组：**高优先级申请 / 值得尝试 / 需要补强 / 暂不符合硬条件 / 信息不足**。

> 分数**不是**录用概率，也不预测竞争者数量。硬条件不符时会直接告诉你哪一条不符。

## 3. 记投递

岗位详情 →「加入投递」，或 `career_application_create`。
「投递管理」支持看板/表格切换，状态下拉直接改，每次变更写入时间线（含 `applied_at` 自动打点）。

超过 14 天没更新的 `已投递` 会出现在「需要跟进」。

## 4. 档位：公司与行业

- 「公司情报」登记官网/招聘页/城市，可设关注状态。
- 让 Agent 说 `研究一下某公司值不值得去` → 它会写研究简报（`career_research_save`）并标来源与数据时点。

## 5. 论坛与面试

系统**不抓**小红书/脉脉/牛客。流程是：

1. 面板「论坛与 Bar」→「用搜索引擎找线索」或让 Agent 跑 `career_social_queries` 拿搜索链接；
2. 你自己打开看；
3. 有用的内容复制到「导入一条经验/面经」，可顺手抽一条观点并选证据等级；
4. 「招聘 Bar 速览」严格分层显示 hard / preferred / observed / unverified。

`career_interview_prep` 会区分**真实面经**（来自导入资料，C 级）与 **AI 生成的练习题**。

## 6. 监控与提醒

「设置」→ 监控规则：

- `job_deadline`：临近截止（默认 7 天内）
- `careers_page`：官方招聘页变化（需要公司档案里有招聘页 URL）
- `keyword_search`：合规搜索发现
- `social_watch`：论坛线索入口

点「立即执行全部」，或让 Agent 跑 `career_monitor_run`。每条提醒含：变化内容、为什么相关、来源、核验时间、建议动作。同一变化不会重复推送（`dedupe_key`）。

失败可在「设置 → 最近运行」看到错误与最后成功时间。

> 自动轮转默认**关闭**（`scheduleEnabled: false`），需要时在 `cordis.patch.yml` 打开。

## 7. 数据管理

「设置 → 数据与隐私」：

- 导出 JSON / 备份数据库（`data/exports/`、`data/backups/`）
- 删除全部数据：两步确认，不可撤销 —— **先备份**

## 常见问题

**Q: 面板里空白的？**
A: 空白状态都写了"该做什么"。岗位库空白 ≠ 没有岗位，只是还没导入。

**Q: PDF 导入失败？**
A: 扫描件或嵌入 CID 字体的 PDF 无法用纯 stdlib 还原文字。用「直接粘贴简历全文」。

**Q: 为什么第三方平台没有数据？**
A: 它们没有开放接口且禁止自动采集。见「设置 → 数据源健康」，那里写明了原因与替代方案。
