# 岗位横向对比增量

## 已实现

- 岗位表新增“对比”勾选列，最多选 5 个；选满后不再添加并给出计数（2/5 …）。
- 工具栏“对比选中（n/5）”打开对比弹窗：逐字段列示公司/岗位/城市/招聘类型/状态/截止/薪酬/学历届别/每周出勤/实习时长/JD 文字完整/匹配分，外加每个岗位的“主要理由”“风险 / 未确认”。
- 差异字段高亮，未知统一显示“未知”，并单列“全部未知的字段”。
- 不产生总分排名；匹配分明确标注不是录用概率，JD 不完整或匹配不可靠时提示不可据此决策。
- 只读接口 `/jobs/compare?ids=a,b`，2–5 个去重岗位，超过只取前 5。

## 验证

新增 3 项离线测试：逐字段对比无混合总分、少于 2 个被拒且上限 5、JD 文字完整度不把缺失当完整；岗位 UI 表头断言同步更新。全量 444 项通过，构建与语法检查通过。

## 未验证与边界

- 对比是弹窗表格，非并排卡片；未做导出对比结果。
- 匹配分基于当前画像，画像未确认时仍是暂定值。
- 当前 GUI 实际点击、窄屏横向滚动与深色主题未验收。
