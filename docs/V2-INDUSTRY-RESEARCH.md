# 行业研究入口增量

## 已实现

- 行业空状态不再只写“让 Agent 用 career_industry_upsert”：提供三个起步模板，一键创建并打开（仍可手动填名称/摘要）。
- 行业详情新增“研究这个行业（有限公开检索）”：
  - **查看检索计划**：最多 3 个关键词（行业+产业链、行业+规模增速、目标企业+岗位），并列出本地公司/岗位/技能只作范围参考。
  - **执行检索并保存线索**：按计划做最多 3 次公开搜索、每次最多 5 条，保存标题/链接/日期为行业研究简报（kind=industry）。
- 报告中固定写入“待核实”小节（统计口径、企业是否真在招、岗位要求与真实工作是否一致），不生成未经核实的数字结论。
- 检索失败逐条记录（含原因），无搜索提供方时明确报错；不静默重试、不伪造结果。

## 验证

新增 4 项离线测试：计划关键词上限与“非结论”标注、检索次数上限与失败计数、无搜索源时的诚实报错、报告含来源链接与待核实段且不含编造百分比。全量 437 项通过，构建与语法检查通过。

## 未验证与边界

- 依赖 Harness 搜索提供方；未配置时界面会提示，不会编造行业结论。
- 搜索结果只是线索，未逐条打开来源正文；引用规模/增速必须回原始统计。
- 当前 GUI 的实际点击、报告打开与窄屏表现尚未验收。
